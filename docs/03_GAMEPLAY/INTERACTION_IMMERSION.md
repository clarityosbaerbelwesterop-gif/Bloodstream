# BLOODSTREAM — INTERACTION & IMMERSION

Status: DOMAIN AUTHORITY

The world should use consistent verbs rather than one-off mission prompts. Core interactions include talk/listen, inspect/read, take/place, open/close, mount/dismount/hitch, restrain/release where relevant, maintain equipment, cook/eat/drink, rest, track/observe, trade and knock/enter.

One context system resolves nearby candidates by intent, gaze, distance and state. UI disambiguates without covering the screen.

Frequently touched objects—doors, saddlebags, holsters, maps, evidence and key props—should feel physical. Important items can be inspected closely for authored detail without hidden-pixel hunting.

Rooms communicate owner, class, work, habits and recent events through arrangement and wear. Mud, dust, rain and snow may affect clothing and selected surfaces as atmosphere rather than chores.

Interaction rules should remain consistent between free roam and missions. Scripting should disable ordinary verbs only when an authored scene truly requires it.
