# Bloodstream

Bloodstream is a large-scale single-player third-person open-world Western action-adventure focused on authored bounty hunting, investigation, tracking, dangerous gunplay, duels, horse travel, camp life, wildlife, living settlements and a complete character-driven story.

## Current phase

**Pre-production / Design Foundation**

The repository currently contains the authoritative design bible and the M1–M28 production roadmap. Unreal Engine implementation begins with M1 after this design foundation is merged.

## Creative north star

Bloodstream is built on contrast: warmth and wonder make later brutality matter. The player begins by living inside a family and community worth loving, then grows into a frontier hunter whose revenge against Frank "The Judge" Vance reveals a larger system of commercial and political violence.

The game takes inspiration from the craft language of classic/revisionist Westerns—landscape, tension, silence, standoffs, dry humor and sudden violence—without copying protected characters, scenes, dialogue, music or plots.

## Production sequence

Bloodstream uses 28 major milestones. M1 establishes the real Unreal Engine 5.8 project/build spine. M6 proves the family/community prologue. M14 delivers Lindstripe at vertical-slice quality. M22 reaches a complete main-story path. M28 produces the real packaged alpha candidate from New Game through epilogue/credits.
